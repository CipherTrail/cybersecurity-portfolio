# Linux User Management & Access Control

## Overview

This activity is part of the Google Cybersecurity Certificate.

The goal of this lab is to practice adding and managing users in a Linux environment using Bash commands.

## Objectives

- Create and manage Linux user accounts
- Manage user access
- Practice Linux authentication concepts
- Use Bash commands to administer users
- Understand how user management relates to cybersecurity

## What I Learned

I practiced managing users and access within a Linux environment using command-line tools. This activity helped reinforce the importance of authentication and access control in cybersecurity.

## Cybersecurity Relevance

User management is an important part of cybersecurity because organizations need to control who can access systems and resources.

Proper account management helps prevent unauthorized access and supports the principle of least privilege.
